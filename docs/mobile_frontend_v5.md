# 手机端前端 v5 实施记录

分支：`feat/mobile-preview-v5`。基于已确认的 HTML v5 预览，使用项目现有 Flutter 页面、生成队列与服务实现。

## 实施范围

- 创作页采用完整图片工作区，左下显示图片自身的分辨率与种子，底部为保存和更多菜单。更多操作为导入局部重绘、官方 Upscale、Enhance。
- 正负提示词分开显示，角色默认不添加，点击加号创建。V5 支持连续坐标定位，其他模型保持项目已有位置能力。
- 局部重绘使用蓝色遮罩、圆形/方格画笔、矩形选择、边缘吸附、遮罩撤销/恢复和绘制时滚动锁定。画笔范围为 8–160，默认 48。
- 成功重绘先进入候选结果，通过前后滑动对比选择一个应用到独立结果层；同批改选会替换该层。结果层可隐藏、删除或保存合成图。后续生成基于源底图及底图绘制内容，结果层不会回写成下一次请求的底图。当前图层会话保留在页面内，未新增跨应用重启的工程文件格式。
- API 配置保留 7877、ikun、NovelAI 官方三个渠道。工具页展示实际返回的额度；没有数据时显示不可用状态，不伪造剩余张数。
- 工具页移除本地超分、独立 Enhance 和发布入口，图片打标入口改为图片解析。图片菜单中的 Enhance 仍使用项目已有官方实现。
- 导演工具页面、ViewModel 和领域实体未修改；页面随应用使用统一主题。

## 验证方法

使用 Flutter 3.47.7 / Dart 3.13.5。Flutter SDK 要求的四个间接依赖在锁文件中同步更新，其余依赖保持原版本与原镜像。

```sh
flutter test --no-pub --concurrency=1 --timeout 60s
flutter analyze --no-pub
```

测试覆盖 320/360/393/412 逻辑像素、100%/200% 字号、提示词焦点与滚动保持、角色坐标、菜单分发、历史导入、官方处理参数与输出尺寸、重绘光栅化与底图保护。数据库测试共用本地数据库名称，因此全套验证串行运行。

2026-10-11 全套串行测试：181 项通过。全仓静态分析：0 errors；仍有既有 warning 和风格 info，不能视为 lint 全绿。连续重绘集成测试通过实际内部队列和本地图片夹具验证两轮自动新增结果层，并比较两次请求底图 PNG 的内容相同。

2026-10-12 局部重绘修订：全套串行测试 194 项通过，候选选择、失败保留、同批替换及跨批预览验证通过。已改为用户确认后添加图层；两次请求底图 PNG 内容相同的保护仍保留。改动文件静态分析无 error/warning，保留 41 条风格 info。详见 [局部重绘修订记录](inpaint_revision_2026-10-12.md)。

遮罩扩张和羽化改为线性时间的精确欧氏距离变换，算法依据为 [Felzenszwalb 与 Huttenlocher 的研究](https://cs.brown.edu/people/pfelzens/dt/)，实现独立编写。逐像素对照覆盖空遮罩、全遮罩、稀疏遮罩、边缘点、单行/单列和多个半径。832×1216 图片、8 像素扩张及羽化的本机光栅计算样本耗时 454 ms；此数字不包含网络请求、PNG 编解码和手机硬件差异。

实际 Flutter 截图可通过 `FRONTEND_CAPTURE` 编译参数生成到 `build/frontend-preview`；截图中的图片和生成参数为测试夹具，不代表已发起真实生成请求。

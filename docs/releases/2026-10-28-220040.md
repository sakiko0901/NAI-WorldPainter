# 1.2.4（220040）· 提示词笔记本与局部重绘更新

发布日期：2026-10-28。源码版本 `1.2.4+218040`，Android ARM64 versionCode `220040`。

本次包含上一公开版本 220037 之后的局部重绘界面整理、画笔改进和提示词笔记本。

## 提示词笔记本

- 文生图正向提示词标题右侧，按「笔记本、复制、展开」排列操作按钮，原展开入口移到标题栏。
- 点击笔记本打开带淡入、缩放与轻移过渡的悬浮窗。
- 支持新增单 tag 或提示词组合，填写标题与内容；列表显示标题和内容预览。
- 支持搜索、编辑、删除、一键复制、一键导入；导入自动处理连接处的中英文逗号，保留内部权重语法和换行。
- 笔记存入本地数据库，关闭窗口或重新打开数据库后保留；保存失败时保留草稿。
- 针对窄屏、放大字号和软键盘调整编辑布局。

## 局部重绘与画笔

- 修复精确圆形遮罩与向外羽化混用时，可能将接口返回图的选区外绿色杂色带入结果的问题。接口请求恢复网格对齐，显示与合成继续使用精确遮罩；羽化仅向选区内过渡。
- 删除「绘制到遮罩 / 图像」选择，画笔和橡皮直接编辑遮罩。

- 点击画笔打开向上滑入的设置窗口，支持圆形、方形以及 1–10 档笔刷大小。
- 圆形笔刷显示与合成遮罩保持涂抹范围；接口请求独立执行必要的网格对齐，蓝色边线显示在精确选区内。
- 方形遮罩保留扩展能力，圆形与方形混用时分别处理，橡皮按笔迹顺序生效。
- 修正实时轮廓切换到精细遮罩预览时，图片尚未解码可能导致的短暂消失。
- 分辨率选择移至工作区左上角，换图入口紧邻右侧；去掉原「选择原图」描述与分辨率外框。
- 移除重复的蒙版专用撤销、重做、隐藏、适应窗口及清空入口，保留统一的工作区撤销 / 重做。
- 工作区菜单支持展开动画，集中收纳扩展、羽化、重绘强度、色彩校正、忽略原图及清空笔迹与遮罩；移除菜单内的放大图片分辨率项。
- 正向、负向提示词与文生图共用编辑样式，移除「重绘提示词」折叠标题。

# 1.2.4 · 界面与 NovelAI 渠道更新

Android ARM64 安装包 versionCode：220037。源码版本：1.2.4+218037。

## 本次更新

- 生成预览帧只刷新结果区域，并隔离加载动画的重绘；页面重新可见时展示最新预览帧。
- 修正 API 渠道卡片交互时的材质层与圆角裁剪，保持卡片背景正常。
- 底部导航取消图标的块状选中背景，改为通过图标颜色表示当前页面。
- 补充官方图生图多角色请求测试：普通/分块图生图保留角色提示词、角色负面词及坐标，V4.5/V5 的流式和非流式请求均通过本地模拟验证，未发现客户端丢弃角色的问题。未调用真实付费生成。
- NovelAI 官方及自定义渠道支持「新增模型」：填写完整模型名称即可添加，自动去除首尾空格并防止重复；重启后保留，添加和切换后即时刷新创作页模型列表。
- 在「工具 → API 配置 → NovelAI 官方」中新增「启用流式传输」开关，自动保存设置。开启时显示中间步骤预览，关闭时等待完整图片返回。
- 官方渠道沿用默认开启；自定义中转默认关闭，也可在平台支持时手动开启。精密参考使用非流式接口。
- NovelAI 官方渠道可填写自定义 URL 和第三方 API Key。URL 留空使用官方地址，官方与各中转地址分别保存凭据；自定义渠道不显示 Opus 体力或积分。
- AI 助手顶栏精简，学习记忆入口移至会话历史旁；输入框支持聚焦扩展，「+」收纳照片、文档和画风收藏。
- 放大「请阐述你的梦」，去掉创作页顶部标题和深色底栏；画廊、生成参数页面加入轻移与淡入淡出过渡。
- 批量生成选中最后一张后恢复自动跟随，查看旧图时保持当前选择。
- 修复离开页面后，账户查询的异步回调仍尝试刷新页面的问题。

# NAI 绘世 1.2.6

发布日期：2026-11-13。源码版本 `1.2.6+218063`，Android ARM64 versionCode `220063`。

## 提示词助手

- 支持按模型设置流式输出，回复过程中可停止，并保留已收到的内容。
- 支持多张参考图和参考用途选择；恢复历史消息时保留关联图片。
- 编辑消息和重试创建会话分支，保留原会话，并提供返回入口。
- 长对话自动生成历史摘要，按上下文预算控制请求。
- 请求前读取当前提示词；提示词在执行前变化时阻止旧内容写入，成功写入后可撤销。
- 完善本地标签匹配、模型选择、连接检测和 WD-Tagger 缓存。

## 界面调整

- 对话内容滚动到顶栏及输入栏后方时逐渐模糊淡出。
- 编辑、重试、复制操作菜单从上向下展开，支持平滑收起和反向切换。
- 系统提示词与 V5 / V4.5 默认提示词统一为折叠卡片，优化文字、间距和编辑框。
- 移除助手设置中的冗余说明和知识库设置入口；保留后台知识库功能。
- 修正生成页 Enhance 弹层顶部横条错位，删去多余说明。
- 完善附件菜单、输入栏及全屏图片预览。

## 更新与安装

- 更新清单直连失败时尝试 GitHub API，并核验 Release、清单和 APK 资源信息。
- 安装包名：`Nai-WorldPainter.apk`；应用包名：`com.naihuishi.nai_huishi`。
- Android 7.0（API 24）及以上，ARM64。
- 发布前核对上一正式版签名、实际版本和 SHA-256；尚未进行真机覆盖安装与性能验证。
